# 配置、密钥与依赖

## 配置和密钥

- 配置通过环境、受控配置文件或依赖注入提供，不硬编码地址、账号、密码、Token、证书和密钥。
- 区分开发、测试、预发布和生产配置；必填配置缺失时快速失败，并指出变量名和安全的修复方向。
- 配置字段有类型、默认值、合法范围、来源和敏感等级；不把整份未校验配置对象透传给业务模块。
- 示例配置使用占位符和假数据，提交前检查密钥、个人数据、生产地址和本地路径。

## 依赖和资源

- 依赖来源、版本、许可证和安全状态可追踪；锁文件或等价机制纳入版本控制。
- 生产构建默认不依赖 CDN、远程脚本、远程字体、远程图片或未锁定的在线包；资源优先随制品交付并支持离线复现。
- 升级、替换或删除核心依赖前，验证公开 API、构建、测试、性能和许可证影响。
- 第三方库不能绕过项目的鉴权、错误、日志、配置和安全边界；不直接复制无法确认来源的代码。
