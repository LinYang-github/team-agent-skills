# 内存与生命周期

## 引用、指针与视图

- T& 表示必需且非空的借用；T* 表示可空或需要指针语义的非拥有借用。
- span 表示连续序列视图，string_view 表示字符视图；二者不延长来源生命周期。
- 不返回指向局部变量、临时对象、短生命周期缓冲区或即将扩容容器的引用、指针、迭代器和视图。
- 接收视图后需要异步保存或跨调用保留时立即复制到拥有类型。
- 不把临时 std::string 隐式转换后的 string_view 保存为成员，不从临时容器创建 span。

## 容器与迭代器失效

- 修改容器前确认引用、指针和迭代器的失效规则；不得依靠“当前容量够用”保证长期正确。
- vector 扩容、erase、排序和重排后重新获取相关视图；unordered 容器 rehash 后不保留迭代器。
- 遍历过程中删除元素使用容器规定的 erase 模式，不递增已经失效的迭代器。
- 不把容器元素地址作为长期标识；需要稳定身份时使用领域 ID 或满足稳定地址契约的存储。
- 并发读取容器时，只要任一线程可能修改就必须同步或使用不可变快照。

## 数组、缓冲区与字符串

- 优先 std::array、std::vector、span 和 std::string，不用裸数组传递长度不明的缓冲区。
- 边界接口同时携带数据和长度；不接受无法验证长度的 C 字符串或内存块。
- 使用 size/empty，不通过哨兵值猜测容器状态；索引来自外部数据时先校验范围。
- 二进制数据使用 byte 或明确无符号字节类型；不要依赖 char 的有符号性。
- 内存复制只用于 trivially copyable 类型，并检查大小、重叠、对齐和字节序；对象序列化不得直接复制内存布局。

## 异步与 lambda 生命周期

- 默认显式列出 lambda 捕获；异步、延迟或跨线程 lambda 禁止使用隐式引用捕获。
- 捕获 this 等同捕获裸指针，不延长对象生命周期；必须证明任务结束早于对象析构，或使用取消/弱所有权。
- promise、future、coroutine frame、回调参数和执行器队列都可能延长生命周期，设计时画出拥有关系。
- 协程参数中的引用和视图必须在挂起期间保持有效；不把调用栈借用跨越 suspend 点。

## 未定义行为防护

- 所有变量在使用前初始化；不读取移出后未定义业务状态、未激活 union 成员或对象生命周期外存储。
- 不违反 strict aliasing；类型重解释优先 bit_cast 或字节视图，并满足尺寸与 trivially copyable 要求。
- 位移操作检查位数、符号和宽度；有符号整数溢出不作为环绕实现。
- 指针对齐、对象构造与 placement new 必须成套处理；普通业务代码不手写对象生命周期管理。
- 不通过 const_cast 修改原本 const 对象，不保留指向已销毁对象的观察者。

## 静态与全局生命周期

- 避免可变全局对象和跨翻译单元静态初始化依赖；优先显式依赖注入和函数局部静态。
- 函数局部静态初始化线程安全，但析构顺序仍需考虑；进程级服务可选择显式生命周期管理。
- thread_local 对象要评估线程池长期存活、析构时机和动态库卸载边界。
- 单例不是生命周期设计的替代；必须说明初始化、并发、重置和测试隔离方式。

## 验证

- Debug/CI 使用 ASan 和 UBSan 捕获越界、use-after-free、未对齐和部分未定义行为。
- 并发共享内存使用 TSan 独立验证；不能用 ASan 作业代替。
- 静态分析重点检查 dangling、未初始化、空指针、越界、错误 move 和生命周期问题。
- 修复根因，不通过延长所有对象生命周期、全量 shared_ptr 或关闭检查掩盖错误。
