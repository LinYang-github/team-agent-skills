# 协议与兼容性

- 跨进程或跨服务消息使用稳定的 envelope，至少包含版本/类型、请求或关联 ID、载荷和错误表达。
- 载荷解析与业务处理分离；非法载荷不能导致连接或整个服务崩溃，并应记录足够的安全诊断信息。
- 新增字段优先保持向后兼容；删除字段、改变语义或改变默认值时提供版本、迁移或兼容适配层。
- 调用方根据机器可读类型/错误码处理，不依赖展示文案、字段顺序或字符串拼接。
- 长任务明确接收、开始、进度、完成、失败、取消和超时状态；重复消息需要幂等键或去重策略。
- 未知消息类型、未知字段和版本不匹配要有明确策略：拒绝、忽略、降级或协商，不能静默产生错误状态。
- 协议测试使用固定夹具覆盖旧版本、新版本、缺字段、额外字段、非法类型和重复投递。
