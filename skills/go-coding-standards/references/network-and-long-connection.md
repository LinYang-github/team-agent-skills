# HTTP 与长连接

- HTTP Client、Server、WebSocket 或其他长连接必须设置连接、读、写和总超时；长连接也要有空闲检测和取消路径。
- 一个连接的读写职责明确；需要并发写入时通过单一写协程、串行队列或等价机制保护连接。
- 对消息大小、请求体、并发连接、缓冲区和每个客户端的资源使用设置上限。
- 心跳、超时和关闭流程要成套设计；收到断连后清理订阅、挂起请求、定时器和缓存。
- 重试只用于明确可重试且幂等的操作；使用退避、最大次数、最大等待时间和抖动，避免重连风暴。
- 连接错误、超时、取消、协议错误和服务端拒绝要区分记录和返回；不能把所有断连都当成同一类成功重试。
- TLS、认证、Origin/来源和协议升级的安全边界由具体协议和部署环境明确验证。

## 验证

- 测试慢客户端、慢服务端、超大消息、心跳丢失、半关闭、重复关闭、网络抖动、重连和服务重启。
