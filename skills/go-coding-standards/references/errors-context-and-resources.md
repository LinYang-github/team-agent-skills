# Go 错误、Context 与资源

- 使用显式 error 返回值；错误需要操作上下文时使用 fmt.Errorf 的包装语义或项目统一错误类型，并保留根因。
- 调用方使用 errors.Is/errors.As 或项目定义的稳定判定方式，不比较错误字符串。
- context.Context 作为请求或任务的第一个参数传递，不存入长期结构体，不用 nil 表示缺少 context。
- 网络请求、数据库、文件、子进程和长任务传递 context，并设置截止时间、取消和资源上限。
- 获取资源后尽早安排释放：文件、响应体、连接、锁、Ticker、临时目录和子进程都覆盖错误路径。
- 只有不可恢复的程序初始化错误或违反内部不变量才考虑 panic；库和业务代码不把 panic 当作普通错误处理。
