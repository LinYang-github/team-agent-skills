# 快捷键与键盘交互规范

本文件规定快捷键和键盘交互如何被界面表达和验收。它不要求所有系统都增加快捷键；只有当系统已经提供或产品确认需要快捷键时，才按本规范设计。快捷键是桌面效率的渐进增强，不能替代可发现的鼠标操作、按钮、菜单或表单控件。

## 设计原则

- 只为高频、稳定、语义明确的操作设计快捷键；低频、危险或容易误解的操作优先保留文字入口。
- 同一产品内相同快捷键尽量保持相同语义，不因页面切换而改变含义。
- 快捷键应提升连续任务效率，不为“看起来专业”而堆叠大量组合键。
- 快捷键必须有明确作用域：全局、页面级、区域级或编辑器级；当前焦点和上下文决定哪个作用域优先。
- 核心操作必须同时提供可见的界面入口；用户不知道快捷键时仍应能完成任务。

## 快捷键分层

### 全局快捷键

- 全局快捷键只用于跨页面稳定存在的能力，例如打开帮助、聚焦全局搜索、显示快捷键清单或关闭当前浮层。
- 不抢占浏览器和操作系统保留快捷键，例如地址栏、刷新、切换标签页、开发者工具等。
- 全局快捷键数量保持克制，避免与系统、浏览器、输入法和辅助技术冲突。

### 页面与区域快捷键

- 页面级快捷键服务于当前页面任务；区域级快捷键只在表格、树、流程图、时间线或编辑器获得焦点时生效。
- 列表、表格和树可以使用方向键、`Enter`、`Space` 等自然键盘操作，但必须有清晰的选中态、展开态和焦点态。
- 编辑器或流程图中的快捷键应在进入该模式后生效，并提供退出方式，例如 `Esc` 或返回普通浏览模式。
- 当快捷键存在父级和子级冲突时，优先使用当前焦点所在区域的语义，离开区域后恢复上一级作用域。

## 按键选择与平台差异

- 优先使用用户熟悉的 `Esc`、`Enter`、`Space`、方向键、`Tab` 等基础键；组合键只用于确有频率价值的任务。
- 避免只使用单个字母作为全局快捷键，避免在用户输入文本、搜索和编辑内容时误触。
- 展示快捷键时根据平台显示 `⌘` 或 `Ctrl` 等对应符号，不让用户自行猜测平台差异。
- 快捷键名称、大小写、连接符和顺序在整个产品内保持一致；菜单、工具提示和帮助面板使用同一写法。
- 不依赖无法观察的长按、连续击键或复杂多键序列作为关键操作入口。

## 输入、焦点与可访问性

- 输入框、文本域、可编辑表格、代码编辑器和组合控件获得焦点时，默认不触发页面级快捷键；确需例外时必须有明确产品语义。
- `Tab` 顺序应符合视觉和任务顺序；焦点不可被弹窗、抽屉或浮层吞掉，关闭后应恢复到合理的触发控件。模态框的初始焦点、焦点陷阱、恢复、`Esc` 和 `Enter` 行为遵循 [弹层与反馈规范](feedback-and-overlays.md)。
- 快捷键触发后提供可识别反馈：焦点移动、选中态变化、面板打开、状态提示或操作结果，不让用户处于“是否生效未知”的状态。
- 不只用颜色或声音表示快捷键结果；焦点环、文字状态和可访问名称应在浅色/深色主题下都清晰。
- 快捷键不能破坏浏览器原生文本编辑、复制粘贴、撤销重做和辅助技术行为。

## 可发现性与危险操作

- 可用快捷键在按钮工具提示、更多菜单、命令面板或帮助面板中可发现；不要求用户阅读外部文档才能知道。
- 工具提示只在有足够空间时显示快捷键，不因提示导致按钮折行或遮挡主要内容。
- 删除、清空、覆盖、发布、提交等危险操作不能只依赖快捷键，也不能仅按下快捷键就绕过二次确认。
- `Esc` 默认用于关闭弹窗、取消临时选择、退出局部模式或停止可取消任务；存在多层弹层时只作用于最上层，具体规则遵循 [弹层与反馈规范](feedback-and-overlays.md)。
- 快捷键不可用、被禁用、无权限或处于加载状态时，应保持与按钮相同的禁用和反馈语义。

## 军事软件与工作台建议

- 在持续观察、数据比对、树节点维护、表格筛选和流程编辑等桌面任务中，优先考虑减少鼠标往返的快捷键。
- 对高频导航、聚焦筛选、切换面板、刷新数据、定位节点和打开详情等操作，可提供简单、稳定、可记忆的快捷键。
- 不使用复杂快捷键替代关键确认、权限判断或状态说明；快捷键只触发已在界面上可理解的动作。
- 工作台中应显示当前焦点或快捷键作用区域，避免用户在多个面板之间误操作。
- 快捷键清单应按全局、页面和当前区域分组，优先展示当前上下文可用的按键。

## 验收清单

涉及快捷键时，至少检查：

1. 不使用快捷键也能完成核心任务。
2. 快捷键在正确作用域生效，离开作用域后不会误触发。
3. 输入框、编辑器、弹窗和浮层中的焦点行为符合预期。
4. 快捷键在菜单、工具提示和帮助入口中可发现，平台符号显示正确。
5. 浏览器/系统保留键、文本编辑和辅助技术行为未被破坏。
6. 危险操作仍有二次确认，快捷键不会绕过权限和状态约束。
7. 浅色/深色、默认/禁用/加载/无权限状态下的焦点和反馈都可识别。
