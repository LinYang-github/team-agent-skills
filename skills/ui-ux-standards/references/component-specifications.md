# 正文组件规格

本文件集中规定桌面端正文工作区中常用组件如何使用基础令牌。基础字号、间距、圆角、控件高度和图标尺寸以 [设计基础规范](design-foundation.md) 为唯一来源；本文件只负责组件映射、状态和适用场景。

## 使用规则

- 新项目没有成熟组件基线时直接采用本文件默认规格。
- 已有项目先将组件库变量映射到这些语义规格，不为统一外观立即替换组件库。
- 一个产品可以选择默认密度或紧凑密度，但同一页面、操作组和表单行不得混用多套近似高度。
- 组件专属值只在本文件定义；页面样式不得复制后轻微修改。
- 品牌差异优先调整颜色、字体家族和标志，不随意改变控件高度、圆角层级和状态结构。

## 正文布局

| 项目 | 默认规格 |
| --- | --- |
| 内容区水平内边距 | 24px |
| 紧凑工作台水平内边距 | 16px |
| 页面标题到首个内容区 | 16～20px |
| 同级区块间距 | 20～24px |
| 区块标题到内容 | 12px |
| 表单字段纵向间距 | 16px |
| 行内控件间距 | 8px |

- 同一页面只能选择一种主要内容边距；局部工作台可以使用紧凑边距，但要有明确容器边界。
- 连续阅读内容控制行长；表格、画布和多面板工作区不机械设置文章式最大宽度。
- 内容层级优先使用间距、对齐和背景差异，不把每个区块包成卡片。

## 按钮

默认按钮为紧凑矩形，圆角 4px，正文工作区默认高度 32px。

| 规格 | 高度 | 字号 | 水平内边距 | 图标 | 使用场景 |
| --- | --- | --- | --- | --- | --- |
| 紧凑 | 28px | 13px | 10px | 14～16px | 表格行操作、紧凑工具栏 |
| 默认 | 32px | 14px | 12px | 16px | 页面、表单和弹窗的普通操作 |
| 大型 | 36px | 14px | 16px | 16～18px | 向导关键步骤、低密度表单 |

- 默认文字按钮最小宽度 64px；确认、取消等弹窗页脚按钮建议不小于 72px，但不强制所有按钮等宽。
- 图标加文字时二者间距 6px；纯图标按钮的点击区域与同组控件等高，默认 32 × 32px。
- 主、次、文字、危险按钮使用相同高度和圆角，不通过放大主按钮或缩小次按钮表达层级。
- 图标位于文字前；仅“下一步、继续、进入”等明确方向性动作可将方向图标放在文字后。
- 纯图标按钮必须有可访问名称和悬浮提示；危险或含义不明确的操作保留文字。
- 加载状态保持原宽度，显示进度并阻止重复提交；禁用状态不能只降低透明度到难以辨认。
- 普通按钮不得使用完全圆角。圆形按钮只用于明确的单图标操作，且不得与普通文字按钮混在同一操作组中争夺层级。

## 输入框、选择器与文本域

| 组件 | 默认规格 |
| --- | --- |
| 输入框、选择器、日期控件 | 32px 高，14px 字号，4px 圆角 |
| 紧凑筛选控件 | 28px 高，13px 字号，4px 圆角 |
| 水平内边距 | 10～12px |
| 前后缀图标 | 16px |
| 文本域 | 最小 80px 高，14px / 22px，4px 圆角 |
| 字段说明与错误 | 12px / 18px |

- 同一表单行的输入框、选择器和按钮保持等高。
- 占位文本只提供示例或输入提示，不代替标签、单位和必填说明。
- 错误态同时使用边框、图标或文字说明，不只改变颜色；错误文本紧邻字段并保留修复空间。
- 只读字段与禁用字段视觉不同：只读可选择和复制，禁用不可交互。
- 搜索框清空、密码显隐、日期选择等内嵌图标至少保留 28 × 28px 可点击区域。

## 表单结构

| 项目 | 默认规格 |
| --- | --- |
| 表单标签 | 13px / 20px，500 |
| 必填标记 | 靠近标签，不单独占列 |
| 字段说明 | 12px / 18px |
| 字段纵向间距 | 16px |
| 分组间距 | 24px |
| 分组标题 | 16px / 24px，600 |

- 标签宽度根据最长常用标签和布局确定，一个表单内保持一致，不跨系统固定为某个像素值。
- 字段说明只补充格式、范围或影响，不使用低对比小字重复标签和页面说明。
- 行内表单用于搜索和少量条件；复杂录入使用纵向或栅格分组，不压缩成一行。
- 保存操作在长表单中保持可发现，并明确未保存、保存中、成功和失败状态。

## 复选框、单选框与开关

| 组件 | 默认规格 |
| --- | --- |
| 复选框、单选框图形 | 16 × 16px |
| 图形与文字间距 | 8px |
| 选项文字 | 14px / 22px |
| 紧凑开关 | 32 × 18px |
| 默认开关 | 36 × 20px |

- 开关只用于立即生效的二元状态；需要提交或影响较大的选择使用单选、复选或明确按钮。
- 选项的整行标签区域可点击，不要求用户精确点击小图形。
- 状态不能只靠颜色，勾选、圆点、位置或文字必须同时表达。

## 表格

| 项目 | 紧凑 | 默认 |
| --- | --- | --- |
| 表头高度 | 32px | 36px |
| 数据行高度 | 32px | 40px |
| 字号 / 行高 | 13px / 20px | 13px / 20px |
| 单元格水平内边距 | 8px | 12px |
| 行内图标按钮 | 28 × 28px | 28 × 28px |

- 同一张表只使用一种密度；需要展示两行信息时采用明确的双行行高，不让内容把普通行随机撑高。
- 表头字重默认 600，数据正文 400～500；数值按位数和比较任务右对齐，普通文本左对齐。
- 表格外容器圆角默认 6px；内部单元格不逐格使用圆角和重边框。
- 行悬停、当前行、勾选、禁用、错误和新增变化具有独立状态，不能只依赖相近背景色。
- 行操作优先保留一个或两个高频操作，其余进入更多菜单；操作列不得挤压核心字段。
- 表格工具栏默认不低于 40px，筛选控件和操作按钮遵循同一密度。

## 树与层级列表

| 项目 | 紧凑 | 默认 |
| --- | --- | --- |
| 节点高度 | 28px | 32px |
| 节点文字 | 13px / 20px | 13px / 20px |
| 每级缩进 | 16px | 20px |
| 展开与类型图标 | 16px | 16px |
| 节点操作 | 28 × 28px | 28 × 28px |

- 根节点、父节点和叶节点通过图标、缩进、连接关系或文字层级共同表达，不只改变颜色。
- 选中态保持 4px 以内圆角；不得把每个节点做成独立卡片。
- 常用节点操作在悬停、选中或聚焦时就近出现，并预留空间避免出现后推动文字折行。
- 节点名称单行省略时提供完整查看；编辑状态不得破坏层级和操作可达性。

## 卡片、面板与分组容器

| 组件 | 圆角 | 默认内边距 | 使用方式 |
| --- | --- | --- | --- |
| 信息分组面 | 4～6px | 12～16px | 轻量分组，可无边框 |
| 普通卡片或面板 | 6px | 16px | 独立内容单元 |
| 工作台主面板 | 4～6px | 12～16px | 强调空间利用和独立滚动 |

- 卡片标题默认 14px / 22px、600；承担页面区块标题时使用 16px / 24px、600。
- 面板头部推荐 40～44px 高，操作使用紧凑按钮；没有标题和操作时不保留空头部。
- 同一内容最多使用一个主要边框层级；嵌套区域优先用间距、分隔线和背景层级。
- 不为普通静态卡片增加重阴影；阴影保留给浮层、拖拽和悬浮状态。

## 标签、状态与筛选条件

| 类型 | 高度 | 字号 | 圆角 |
| --- | --- | --- | --- |
| 紧凑状态标签 | 20px | 12px | 2～4px |
| 默认标签 | 24px | 12～13px | 4px |
| 可移除筛选条件 | 28px | 13px | 完全圆角或 6px |

- 状态标签使用“文字＋语义色”，必要时增加图标；颜色不是唯一表达。
- 胶囊形只用于筛选条件、可移除标记或明确的状态语义，不用于普通按钮和导航。
- 标签文字保持短且可直接理解，不在标签中放长说明。

## 标签页、分段选择与分页

| 组件 | 默认规格 |
| --- | --- |
| 页面标签高度 | 40px，14px / 22px |
| 标签当前指示线 | 2px |
| 分段选择器 | 32px 高，4px 圆角 |
| 分页按钮 | 32 × 32px，4px 圆角 |
| 紧凑分页按钮 | 28 × 28px，4px 圆角 |

- 页面标签默认使用文字和底部指示线，不额外做成一排胶囊按钮。
- 分段选择器只表达少量互斥视图或模式，不替代一级导航和流程步骤。
- 当前页、禁用、悬停和键盘聚焦状态均需清晰；分页控件不依赖只有图标且无名称的按钮。

## 下拉菜单、提示与浮出面板

| 组件 | 默认规格 |
| --- | --- |
| 下拉菜单项 | 32～36px 高，13～14px |
| 下拉菜单圆角 | 6px |
| 工具提示 | 12px / 18px，6px 8px 内边距，4px 圆角 |
| 普通浮出面板 | 6px 圆角，12～16px 内边距 |

- 菜单按任务排序，危险操作与普通操作分组并使用明确文字。
- 工具提示用于名称、快捷键或简短解释，不承载必须阅读的业务内容。
- 浮层保持在视口内，不遮挡触发控件和当前任务的关键状态；关闭后焦点返回触发控件。

## 模态框与抽屉尺寸

| 类型 | 建议宽度 | 圆角 | 内容内边距 |
| --- | --- | --- | --- |
| 确认与短表单 | 420～480px | 8px | 20～24px |
| 普通表单与详情 | 600～720px | 8px | 24px |
| 复杂配置 | 800～960px | 8px | 24px |

- 模态框头部和页脚建议 52～56px 高；按钮使用默认 32px 规格。
- 宽度根据任务和内容选择，不把全部弹窗固定为同一大尺寸；高度原则上不超过可用视口的 80%，正文区域独立滚动。
- 遮罩、初始焦点、焦点陷阱、键盘、关闭行为、按钮顺序、危险确认和二级弹窗统一遵循 [弹层与反馈规范](feedback-and-overlays.md)。

## 空状态与加载

- 局部加载使用与内容结构相符的占位或轻量进度，不让整个页面跳动。
- 空状态图标默认 40～48px，标题使用 14px / 22px、600，说明使用 13px / 20px；不使用巨型插画占据工作台。
- 空状态只有存在明确下一步时才显示操作按钮，按钮遵循默认规格。
- 长任务使用进度和阶段状态，普通状态不持续闪烁或使用大面积动画。
- Toast、Notification、Banner 和持久通知的选型、位置、时长、堆叠与文案统一遵循 [弹层与反馈规范](feedback-and-overlays.md)。

## 组件状态矩阵

所有可交互组件至少验证：

| 状态 | 统一要求 |
| --- | --- |
| 默认 | 边界、文字和可操作性清晰 |
| 悬停 | 使用轻量背景、边框或文字变化，不位移和缩放 |
| 按下 | 短暂加深，不制造立体凹陷 |
| 聚焦 | 2px 可见焦点环，不被选中态或溢出裁剪 |
| 禁用 | 不可交互且仍可辨认；必要时解释原因 |
| 加载 | 保持尺寸，阻止重复操作并提供进度 |
| 错误 | 文字说明与视觉状态并用，提供修复路径 |
| 选中 | 颜色之外同时使用标记、背景、字重或位置 |

## 允许偏离的条件

只有以下情况可以偏离默认规格：

- 项目已有成熟、成体系的设计令牌，并能完整映射同等语义与状态。
- 目标硬件、触控、无障碍或值守环境明确要求更大点击区域。
- 数据密度、画布工具或实时控制任务经验证需要紧凑规格。
- 品牌组件具有正式规范，且不会破坏同类组件的一致性和可访问性。

偏离时记录采用值、适用组件、原因和两个主题下的验证结果。不得因为组件库默认值或单个页面视觉偏好直接偏离。
