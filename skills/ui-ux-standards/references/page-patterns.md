# 页面结构模式

这些是可复用的结构，不是必须套用的模板。先判断用户任务和信息关系，再选择模式。

## 军事软件工作台优先

军工软件通常需要持续监视、快速比较、分阶段操作和保留上下文，优先考虑桌面工作台而不是互联网式长页面：

- 使用稳定的应用壳、当前对象上下文、任务工具栏、主工作区和辅助检查区。用户切换内容时，关键上下文和主要操作不要随滚动消失。
- 将高频观察区、主操作区、属性/详情区、日志/告警区按任务关系分区；只有确有因果或流程顺序时才使用纵向串联。
- 表格、时间线、树、流程图、指标卡和结果面板可以组合，但每个区域都要有明确任务，不为填满屏幕而增加卡片。
- 允许中高密度，但通过间距、对齐、层级背景和固定面板宽度保持可读性；“信息多”不等于“边框多”。
- 需要横向比较或同时操作的内容优先并列布局；需要连续阅读、填写、审批或报告叙述的内容才采用长页面。
- 优先支持桌面窗口缩放、键盘操作和独立区域滚动；当前技能覆盖的项目不要求移动端布局，除非另行声明移动端范围。

### 长页面的使用边界

适合长页面：任务书/报告阅读、分组表单、审查清单、向导确认和需要顺序阅读的说明。

不宜默认使用长页面：实时态势、试验控制、指标监视、资源调度、复杂表格、树状管理和需要同时查看上下游关系的工作区。此类场景应优先采用固定工具栏、分栏、标签页、抽屉或可调整面板。

### 工作台验收问题

- 用户是否始终知道当前项目、试验、任务或数据范围？
- 主工作区是否保留最重要的判断和操作，辅助信息是否可收起？
- 滚动一个区域是否会丢失另一个区域所需的上下文？
- 面板宽度、表格列和日志区域是否有合理的最小值，是否会因百分比布局导致折行或截断？
- 告警、异常和进行中状态是否能在不打断主要工作的情况下被发现？

## 应用壳

产品身份、全局导航、当前作用域、阶段导航、页面标题、面包屑和全局工具区遵循 [应用壳与导航规范](application-shell-and-navigation.md)。本文件只补充不同页面类型在应用壳内的内容结构。

### 页面标题与辅助文案

页面标题或模块名称已经能直接表达当前任务时，不添加同义的解释性副标题。副标题仅用于补充标题本身无法表达、但用户完成当前任务所必需的作用域、状态、限制条件或下一步动作；只是改写标题含义的文案应删除。

### 浏览器标签页

浏览器标签页是应用壳在浏览器外部的延伸，应统一使用“当前页面 · 产品名”的标题格式，并使用与应用壳一致的产品图标。页面标题只承担识别当前任务的职责，不重复页面副标题，也不放置宣传语。

- 列表/工作台：方案管理 · 凌云平台
- 详情页：城市低空巡检方案 · 方案管理 · 凌云平台（仅在对象识别有价值时使用）
- 设置页：偏好设置 · 凌云平台

路由元信息应是标题的单一来源；favicon 应通过随构建产物交付的本地资源声明。应用壳、favicon 和 theme-color 使用同一产品身份，不因页面临时需求更换图标。

## 列表/表格页

适用于任务、用户、试验、资源等对象集合：

1. 标题和对象范围。
2. 主要新增或导入操作。
3. 搜索、筛选、排序和视图切换。
4. 表格或列表。
5. 分页、批量操作和空/异常状态。

当行操作较多时，使用最常用的可见操作加“更多”菜单，避免操作列挤压主要数据。

## 详情/工作台

适用于一个当前项目、试验、指标或资源：

- 上方保留清晰的对象名称、状态和作用域。
- 页面内导航按工作阶段或任务分组，而不是按数据库表分组。
- 主工作区优先显示当前阶段的核心信息和下一步操作。
- 高风险或破坏性操作放入次级操作区。

## 向导/流程页

适用于新增复杂对象、配置方案和多阶段设计：

- 步骤名称描述用户任务，不使用含义不明的“步骤一、步骤二”。
- 允许回看和修改已完成步骤；无法修改时说明原因。
- 当前步骤只收集该阶段必须信息，其他信息延后。
- 最后确认页总结关键选择、风险和提交结果。

## 仪表盘/工作台

- 卡片数量服从任务，不为了填满页面而增加统计。
- 首屏先给出需要处理的事项、关键状态和趋势，再展示明细。
- 当数据提供这些信息时，图表应清楚表达标题、单位、时间范围、空状态和异常说明；本技能不定义业务单位或数据质量规则。
- 不使用纯装饰性渐变、发光或过多彩色卡片制造“丰富感”。
- 对需要持续操作的场景，优先使用可调整的多面板工作区、固定上下文和独立滚动，而不是把所有指标纵向堆成长页面。

## 设置/配置页

- 按用户目标分组，常用设置优先。
- 需要即时生效的设置明确反馈；批量保存的设置固定保存入口和未保存状态。
- 危险区域与普通配置分开，说明影响范围和恢复方式。

## 认证页

- 登录、注册、授权、找回密码分别表达各自任务。
- 减少非必要信息和装饰；错误信息贴近字段且不泄露敏感内容。
- 深色/浅色、语言切换和品牌标识的位置保持稳定。
