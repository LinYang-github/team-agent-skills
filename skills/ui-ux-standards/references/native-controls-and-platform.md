# 原生控件与平台表面

## 统一原则

核心业务页面不能把浏览器或操作系统默认的复杂视觉表面当作设计方案。不同浏览器、系统、缩放比例和主题可能改变下拉面板、日期面板、颜色面板、滑块、开关、提示气泡和弹窗的外观。

统一组件负责：

- 尺寸、圆角、边框、阴影和层级
- 浅色/深色主题及对比度
- 选中、禁用、错误、加载和聚焦状态
- 键盘导航、焦点返回和弹层定位
- 长文本、空数据、搜索和滚动行为

## 默认替换范围

工作台中的 `select`、日期/时间/颜色选择器、range 滑块、switch、复杂 checkbox/radio、复杂 `dialog`、浏览器校验气泡和 `title` 提示，默认使用项目统一组件。

“统一组件”不等于全部重画：文件选择、打印、系统认证等系统级能力可以继续使用系统原生窗口；自定义上传按钮、进度和错误展示应保持产品统一。

## 例外验收

使用原生控件时必须满足：

1. 选项少且稳定，默认面板不会破坏页面层级。
2. 原生行为对当前操作有明确价值。
3. 键盘、焦点、错误和禁用状态可用。
4. 例外范围局限在具体组件或页面，并记录原因。
5. 不把原生控件作为其他页面的公共视觉基线。

## 视觉验收

自定义选择器和浮层遵循正文组件规格：输入控件默认 32px 高、4px 圆角；紧凑筛选器 28px 高；菜单项 32～36px 高、6px 圆角。展开面板应在两个主题和不同内容长度下保持可读、可定位、不被容器裁剪。
