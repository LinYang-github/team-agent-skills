# 桌面窗口适配规范

本文件面向桌面优先的企业系统和军工工作台，规定页面如何适应不同桌面窗口、浏览器缩放和多面板任务。它不要求移动端布局，也不以“所有内容永远塞进一屏”为目标。

## 窗口与布局基线

- 先定义页面的最小可用窗口宽度、常用工作宽度和宽屏上限；内容区、导航、工具栏和辅助面板分别说明伸缩或固定策略。
- 核心任务区保持稳定的最小宽度，窄窗口优先收起低频辅助区、转为抽屉或提供横向滚动，不压缩到文字和控件无法识别。
- 宽屏不让正文、表单和长文本无限拉伸；通过最大宽度、分栏或辅助面板保持阅读和比较效率。
- 页面壳、上下文栏和主工作区的层级在窗口变化时保持不变，不能因换行导致主要操作跳到不可预期的位置。
- 固定顶部/侧边区域必须为内容保留明确的可用空间，避免遮挡表格、焦点环、提示和弹层。

## 多面板与滚动

- 工作台中的主面板、辅助面板和详情区明确谁承担页面滚动，避免整个页面与多个嵌套区域同时滚动。
- 固定工作台必须先建立“视口—页面壳—工作区”的高度契约：页面根节点占满视口并隐藏页面级溢出，顶部导航/上下文区占固定或可计算高度，工作区通过 min-height: 0 占用剩余空间；列表、详情、日志等内容面板各自承担纵向滚动。
- 可滚动面板不能只满足“能滚动”，还要有最低舒适高度；页面标题、统计摘要和上下文栏等非核心区域不得把主列表/详情区挤压成很矮的滚动框。
- 对矮窗口必须定义降级策略：优先压缩低优先级顶部区域；若仍低于工作区最低高度，允许工作台外层出现可理解的页面滚动，避免裁剪主列表、详情和固定操作。
- 使用 CSS Grid/Flex 组合多面板时，工作区及其可滚动子项必须允许收缩（通常需要 min-height: 0; min-width: 0）；只设置 height: 100% 或 min-height 不能替代这一约束。
- 验收时必须同时检查：页面根节点不可纵向滚动；主列表滚动不带动详情；详情滚动不带动列表；固定工具栏和上下文在滚动时保持可见；面板内容不足时不出现无意义滚动条。
- 面板可收起、调整宽度或切换布局时，保持当前对象、筛选、选中项和滚动位置；无法保持时给出可理解的重置反馈。
- 横向滚动只服务于确实需要比较的表格、矩阵和时间线；滚动条、固定列和当前行/列关系应可发现。
- 弹窗、抽屉、下拉菜单和工具提示不能因窗口边缘被裁切；必要时改变展开方向或提供独立滚动。
- 大型流程图、画布和图表应支持缩放、平移、重置和定位，不用无限缩小内容来适配窗口。

## 缩放、高 DPI 与输入

- 在常用浏览器缩放级别和高 DPI 显示器中检查文本、图标、边框、焦点环和点击目标，不以单一开发机像素值作为依据。
- 浏览器缩放或系统字体放大后，优先允许文字换行、面板滚动和工具栏收起；不要通过裁剪文字或隐藏操作“解决”溢出。
- 鼠标、键盘和触控板的主要操作保持可用；拖拽、悬停和精细图表操作提供键盘或按钮替代。
- 弹窗关闭、路由切换和面板收起后焦点仍应落在可见、可解释的控件上。

## 状态与持久化

- 窗口布局、面板宽度、密度和可见列等用户偏好可以持久化，但必须有版本、默认值和重置入口。
- 屏幕尺寸变化、浏览器刷新和恢复会话时，不恢复已经不存在或没有权限的面板、路由和对象。
- 数据加载、失败、空状态和权限变化不能因窗口重排而丢失主要上下文和下一步动作。

## 验收矩阵

至少检查：

1. 常用桌面宽度、较窄窗口和宽屏上限。
2. 浏览器缩放和系统字体放大后的可读性。
3. 多面板收起、展开、调整宽度和独立滚动。
4. 长标题、大表格、深层树、图表和弹窗边缘状态。
5. 键盘焦点、快捷键、拖拽替代和主题切换。
6. 常用桌面高度、较矮窗口和极矮窗口下，滚动面板仍保留最低可用视野；检查是否出现“滚动条存在但可视内容过少”的伪工作区。

## 工作台实现契约

当页面被定义为桌面工作台、列表/详情工作区或多面板持续操作界面时，默认采用以下结构语义：

    <div class="workbench-shell">
      <header class="workbench-header">固定上下文与全局操作</header>
      <main class="workbench-body">
        <section class="workbench-panel workbench-list">列表/表格，独立滚动</section>
        <aside class="workbench-panel workbench-detail">详情/日志，独立滚动</aside>
      </main>
    </div>

对应的最小布局契约为：

    .workbench-shell { height: 100vh; overflow: hidden; }
    .workbench-body { min-height: 0; overflow: hidden; }
    .workbench-panel { min-width: 0; min-height: 0; overflow-y: auto; }

这不是要求所有项目复制类名，而是要求实现具备同等语义。若页面需要自然长页面（例如报告、向导或连续阅读表单），必须在设计记录中说明原因，不得因面板内容撑高而意外形成长页面。
