# 应用壳与导航规范

本文件规定桌面端企业应用中产品身份、全局导航、当前上下文、阶段导航、页面标题、面包屑和全局工具区的职责与选型。它统一应用壳的语义和验收方式，不要求所有产品采用相同的导航方向、品牌颜色或业务菜单。应用壳专属尺寸在本文件定义；进入正文区域后，按钮、表单、表格、树、卡片和弹层统一遵循 [正文组件规格](component-specifications.md)。

## 应用壳职责

应用壳从外到内按需组合以下层级：

    应用顶栏
    ├─ 产品身份
    ├─ 一级导航（顶部导航时）
    └─ 全局工具与账户
    上下文栏（按需）
    └─ 当前任务、对象或作用域
    模块/阶段导航（按需）
    └─ 当前模块内的阶段、标签或子页面
    页面标题与操作区
    └─ 当前页面任务、状态和页面级操作
    内容工作区

各层分别回答不同问题：

- 产品身份：当前属于哪个产品。
- 一级导航：当前位于哪个主要模块。
- 上下文栏：当前正在处理哪个对象或作用域。
- 阶段导航：当前模块内处于哪个阶段或子任务。
- 页面标题：当前具体任务是什么。
- 页面操作区：当前页面可以执行什么操作。

只显示完成当前任务所需的层级。不得为了“结构完整”同时堆叠空上下文栏、单项标签栏、装饰性面包屑和重复标题。

## 产品身份区

- 产品标志和正式名称位于应用壳稳定位置，通常在顶栏或侧栏顶部的左侧。
- 使用正式产品标志，不使用组件库通用图标、框架默认图标、emoji 或随机占位图标冒充产品身份。
- 产品标志、产品名称、浏览器 favicon 和 theme-color 保持一致；资源随构建产物交付，不依赖在线地址。
- 产品名称保持单行，长名称应有明确的最小宽度、截断或布局降级策略，不挤压主要导航和全局工具。
- 产品身份入口可返回产品默认工作入口；行为在同一产品内保持稳定，并提供可访问名称。

默认组件规格：

| 属性 | 默认值 |
| --- | --- |
| 产品标志 | 32 × 32px |
| 产品名称 | 18px / 700 |
| 标志与名称间距 | 10px |
| 产品区左侧内边距 | 24px |
| 顶部产品区最小宽度 | 220px |
| 侧栏产品区高度 | 与应用顶栏一致，默认 60px |

- 产品名称不折行；空间不足时先按产品定义缩短名称或省略并提供完整提示，不允许挤压到导航和全局工具重叠。
- 产品标志使用原始比例，不通过强发光、重阴影或临时渐变文字制造跨产品统一风格。
- 成熟品牌规范可以调整标志和文字细节，但应保留相同的占位、对齐和溢出契约。

## 一级导航选型

一级导航统一语义，不强制统一方向。根据菜单规模、层级、稳定性和任务关系选择顶部导航或侧边导航。

### 顶部导航

适用于：

- 一级模块数量较少，通常为 3～7 个。
- 模块同级且名称较短。
- 导航结构长期稳定，不会因权限或配置产生大量动态项。
- 模块之间具有明显的工作流或频繁横向切换关系。

要求：

- 导航项不得折行；空间不足时使用明确的“更多”入口，或改用侧边导航，不得持续压缩文字和点击区域。
- 导航位于产品身份区和全局工具区之间的可用中间区域；需要视觉居中时，应在可用区域内居中，不以整个视口绝对居中造成遮挡。
- 图标只辅助识别，不能取代必要文字；当前项同时使用字重、位置标记、背景或下划线，不只改变颜色。
- 顶部导航不承载页面级新增、删除、提交等业务操作。

默认组件规格：

| 属性 | 默认值 |
| --- | --- |
| 导航项高度 | 占满 60px 顶栏 |
| 文字 | 14px / 600 |
| 图标 | 16～18px |
| 图标与文字间距 | 6～8px |
| 水平内边距 | 16～20px |
| 导航项间距 | 4～8px |
| 当前指示线 | 2px，左右缩进 12px |
| 圆角 | 0；不做胶囊导航 |

### 侧边导航

适用于：

- 一级入口较多或存在两级以上层级。
- 菜单名称较长。
- 菜单按角色、权限或配置动态生成。
- 用户需要持续查看分组和层级关系。

要求：

- 一级、二级和分组标题的缩进、字重与展开关系稳定，不使用边框堆叠模拟层级。
- 展开、收起和当前项状态清晰；收起后只显示图标时，每项必须有悬浮提示和可访问名称。
- 动态隐藏菜单后不留下空分组、无意义分隔线或不可到达的当前项。
- 菜单较长时由导航区域独立滚动，产品身份和必要的底部入口保持稳定。

默认组件规格：

| 属性 | 默认值 |
| --- | --- |
| 展开宽度 | 220px |
| 收起宽度 | 60px |
| 导航项高度 | 40px |
| 文字 | 14px / 500，当前项 600 |
| 图标 | 18px |
| 图标与文字间距 | 10px |
| 一级项水平内边距 | 16px |
| 当前指示条 | 左侧 3px |
| 导航项圆角 | 0～4px，不做独立卡片 |

## 导航选中态与状态矩阵

不同导航类型采用固定的默认选中结构：

| 导航类型 | 默认选中态 |
| --- | --- |
| 顶部一级导航 | 柔和主色背景＋主色文字/图标＋底部 2px 指示线 |
| 左侧一级或二级导航 | 柔和主色背景＋主色文字/图标＋左侧 3px 指示条 |
| 页面标签 | 主色文字＋底部 2px 指示线，默认不增加背景 |
| 分段选择器 | 当前项使用填充背景和清晰边界 |
| 阶段/步骤导航 | 当前节点、连接关系和文字状态共同表达 |
| 图标工具模式 | 柔和填充背景＋图标强调 |

顶部和侧边一级导航不使用凹陷、内阴影或立体按压效果表示当前位置；这些效果容易与瞬时按下状态混淆。凹陷式选择只可用于明确的互斥模式或分段控件，且不依赖阴影作为唯一线索。

通用状态矩阵：

| 状态 | 默认表达 |
| --- | --- |
| 默认 | 次要文字色或常规文字色，透明背景 |
| 悬停 | 中性悬停背景＋主要文字色 |
| 当前 | 按导航类型使用固定选中结构，并设置 aria-current |
| 按下 | 背景短暂加深，不位移、不缩放 |
| 键盘聚焦 | 独立的 2px 焦点环，不被当前态覆盖 |
| 禁用 | 禁止交互并降低对比度；需要解释时提供原因 |

同一产品的同类导航不得在不同页面分别使用“仅下划线”“仅变色”“立体凹陷”等多套当前态。

## 阶段导航、标签和面包屑

- 阶段导航表达真实的先后、完成或可达关系；箭头、连接线和步骤编号不得仅作为装饰。
- 页面标签表达同一模块内可并列切换的视图，不用于伪装流程步骤。
- 一级导航、阶段导航和页面标签不得重复承载同一组选项。
- 面包屑只在祖先路径有定位和返回价值时使用；祖先项可导航，末项表示当前位置。
- 不把不可点击的“分类名称 / 当前页面”装饰文字当作面包屑，也不同时用面包屑和页面标题重复完整路径。

## 当前上下文

- 对跨页面或跨步骤持续生效的当前任务、项目、方案、资源或其他业务对象，应在应用壳或上下文栏中持续可见。
- 上下文按“上层作用域—下层对象”排列，名称、层级和切换入口稳定；只有当前页面需要的层级才显示。
- 可以切换的上下文应明确表现为可交互控件；只读上下文不伪装成按钮或下拉框。
- 上下文切换后，标题、导航、内容和辅助面板同步更新；不得出现壳层名称与实际数据作用域不一致。
- 子页面不重复占用内容区展示同一上下文；需要补充状态、限制或版本时使用次级信息，而不是再复制对象名称。
- 上下文视觉保持克制，不与告警、主要操作或执行状态争夺注意力。

默认组件规格：

| 属性 | 默认值 |
| --- | --- |
| 上下文栏高度 | 42px |
| 左右内边距 | 24px |
| 标签文字 | 12px / 600 |
| 当前值文字 | 13px / 700 |
| 图标 | 16px |
| 图标容器 | 24 × 24px，4～5px 圆角 |
| 相邻上下文间距 | 12px |
| 分隔线 | 1 × 18px |

- 当前值保持单行；溢出时省略并提供完整提示。
- 可切换上下文使用轻量按钮或下拉触发器，只读上下文使用文本，不把所有上下文统一做成胶囊标签。
- 上下文图标只辅助识别，标签和值不能因图标存在而省略。

## 页面标题与操作区

- 页面标题使用用户可以理解的任务名称，不使用路由片段、内部组件名或数据库表名。
- 页面标题和导航当前项保持语义一致，但不要求逐字重复；标题可以比导航项更具体。
- 副标题只补充完成任务所需的作用域、状态、限制条件或下一步，不改写标题含义。
- 页面级主要操作靠近页面标题或内容起始位置；视图内原则上只有一个主要操作。
- 次要操作和危险操作与主要操作区分，不把页面操作塞入全局顶栏。
- 标题、上下文和操作区应在页面滚动或工作区局部滚动时保持符合任务需要的可见性。

默认组件规格：

| 元素 | 默认值 |
| --- | --- |
| 内容区页面标题 | 页面标题令牌：20px / 28px / 700 |
| 顶栏紧凑标题 | 区块标题令牌：16px / 24px / 600 |
| 副标题 | 紧凑正文令牌：13px / 20px / 400～500 |
| 面包屑 | 紧凑正文令牌：13px / 20px / 400～500 |
| 标题与副标题间距 | 4～6px |
| 标题区与内容间距 | 16～20px |

- 顶栏只有当前页面名称时，将其作为标题，不伪装成面包屑。
- 面包屑祖先项使用次要文字色并可导航，当前项使用主要文字色且不重复链接自身。
- 使用统一面包屑组件和分隔图标，不用手工输入斜杠、大于号或箭头字符模拟。
- 内容区已经提供完整页面标题时，顶栏不再逐字重复；顶栏可以保留必要的上层上下文。

## 全局工具与账户区

当产品提供相应能力时，全局工具区按稳定的相对顺序组织：

    通知/告警 → 全局助手 → 语言 → 主题 → 设置 → 用户

- 不要求产品展示所有能力；未提供的项目直接省略，剩余项目保持相对顺序。
- 用户入口固定在最右侧，账户资料、偏好和退出等账户操作集中在用户菜单中。
- 系统级设置保留在全局工具区；只影响当前页面或对象的设置放在对应页面或工作区。
- 仅图标工具必须提供悬浮提示、可访问名称以及清晰的悬停、聚焦、激活和禁用状态。
- 普通全局工具不使用持续高亮、胶囊按钮或强状态色争夺主要任务的注意力。

全局图标工具默认规格：

| 属性 | 默认值 |
| --- | --- |
| 点击区域 | 40 × 40px |
| 图标 | 18px |
| 相邻间距 | 4～8px |
| 圆角 | 6px |
| 默认背景 | 透明 |
| 悬停背景 | 中性悬停背景 |
| 已打开/激活背景 | 对应能力的柔和语义背景 |

普通全局工具默认不使用实心圆形背景；圆形优先保留给头像、状态指示或明确具有圆形语义的操作。

### 用户账户入口

- 已登录的桌面应用默认显示“头像＋用户显示名＋下拉箭头”，并将整个区域作为一个交互控件。
- 优先显示真实姓名或昵称，其次显示账号名；角色或岗位不是人名，默认放入账户菜单或账户详情，不作为唯一身份文字。
- 共享终端、值班席位或明确的隐私模式可以只显示岗位或账号标识，但应作为已确认的产品例外。
- 账户资料、偏好和退出等操作集中在账户菜单；退出不长期占据独立顶栏位置。

默认组件规格：

| 属性 | 默认值 |
| --- | --- |
| 头像 | 32 × 32px |
| 紧凑顶栏头像 | 28 × 28px，仅用于低于 56px 的顶栏 |
| 账户按钮高度 | 40px |
| 姓名文字 | 14px / 600 |
| 头像与姓名间距 | 8px |
| 下拉箭头 | 14px |
| 姓名最大宽度 | 96px |
| 内边距 | 6px 10px |
| 圆角 | 4～6px |

- 姓名超出最大宽度时单行省略，并提供完整提示。
- 没有头像时，中文显示名使用首个可识别汉字，拉丁文字使用稳定的首字母缩写；背景色根据稳定用户标识生成，不得每次刷新随机变化。
- 不使用在线头像服务、随机人物图片或与用户无关的通用人物照片作为默认头像。
- 空间不足时优先隐藏姓名，保留头像和账户菜单；头像按钮仍需提供包含身份的可访问名称。
- 在线、忙碌等状态点只在产品已经定义对应状态时显示，不把装饰性绿点伪装成在线状态。

## 默认尺寸令牌

新产品没有成熟应用壳基线时，采用以下桌面端默认值；已有成熟基线可以映射为同等语义令牌，偏离时记录对内容空间和窗口适配的影响：

    --shell-header-height: 60px;
    --shell-context-height: 42px;
    --shell-sidebar-width: 220px;
    --shell-sidebar-collapsed-width: 60px;
    --shell-global-action-size: 40px;
    --shell-product-logo-size: 32px;
    --shell-user-avatar-size: 32px;
    --shell-nav-icon-size: 18px;
    --shell-top-nav-indicator-height: 2px;
    --shell-side-nav-indicator-width: 3px;

- 顶栏与上下文栏组合时，默认固定壳高度约为 102px；不需要上下文栏时不保留空白高度。
- 导航项、上下文项和全局工具保持有限的高度层级，不在同一应用壳中混用多套近似尺寸。
- 侧边栏宽度应保证常用菜单不频繁折行；长文本使用可发现的完整查看方式。
- 数值是默认基线，通过语义令牌管理，不在页面组件中散落硬编码。

## 权限、溢出和状态保持

- 当系统根据权限隐藏或禁用导航项时，可用、只读和不可访问状态保持可理解；本规范不定义权限模型。
- 当前路由变得不可用时，应进入可理解的可用位置，不保留指向不存在页面的选中态。
- 顶部导航空间不足时不得折行；侧边导航内容过长时不得挤压产品身份和账户入口。
- 导航方向切换、侧栏收起、上下文切换或窗口变化时，尽可能保留当前对象、筛选、滚动和工作区状态。
- 导航和标题的数据加载、空值或失败不得导致壳层大幅跳动；必要时使用稳定占位并提供异常反馈。

## 主题、键盘与桌面验收

- 浅色、深色和跟随系统主题下，产品身份、当前项、悬停、聚焦、禁用、告警和用户菜单均可辨识。
- 当前项不能只靠颜色表达；同时使用背景、字重、下划线、侧边标记或 aria-current。
- 键盘可到达一级导航、上下文切换、全局工具和用户菜单；弹层关闭后焦点返回触发控件。
- 浏览器缩放、系统字体放大和较窄桌面窗口下，应用壳层级不改变、主要操作不折行到不可预期位置。
- 固定应用壳为内容区预留准确空间，不遮挡标题、表格、画布、弹层和焦点环。

## 验收清单

1. 产品身份、一级导航、当前上下文、阶段导航和页面标题是否各自只承担一种职责。
2. 顶部或侧边导航的选择是否符合菜单数量、层级、稳定性和任务关系。
3. 当前项是否同时使用颜色之外的识别方式，键盘和读屏是否能识别当前位置。
4. 当前上下文是否持续可见并与实际内容一致，子页面是否避免重复展示。
5. 页面标题、面包屑和浏览器标题是否一致且不重复堆叠。
6. 全局工具、页面操作和工作区操作是否放在正确作用域。
7. 长名称、动态菜单、权限变化、导航溢出和窗口缩放是否有明确降级策略。
8. 浅色、深色、跟随系统、悬停、聚焦、禁用和弹层状态是否完整。
9. 已登录状态是否按默认规则显示头像和用户名称，角色、无头像、长名称和空间不足是否正确处理。
10. 产品标志、导航项、全局工具、上下文栏、标题和面包屑是否符合默认组件规格，偏离是否有明确理由。
