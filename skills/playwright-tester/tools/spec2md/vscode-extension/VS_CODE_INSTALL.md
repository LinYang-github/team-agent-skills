# VS Code 扩展安装指南

## 自动安装（推荐）

1. 打开 VS Code
2. 按 `Ctrl+Shift+P` 打开命令面板
3. 输入 `Extensions: Install from VSIX`
4. 选择本目录下的 `spec2md-1.0.0.vsix`

## 手动安装

1. 在 VS Code 中打开 Extensions 面板
2. 点击右上角 `...` 菜单
3. 选择 `Install from VSIX...`
4. 浏览并选择 `spec2md-1.0.0.vsix`

## 功能说明

- **转换为测试用例MD**：将 Playwright spec 文件转换为 code2doc 测试用例设计表
- **转换为测试执行记录MD**：生成测试执行记录 Markdown
- **转换为用户手册MD**：生成用户手册操作步骤 Markdown

右键点击 `.spec.ts` 文件即可使用。
