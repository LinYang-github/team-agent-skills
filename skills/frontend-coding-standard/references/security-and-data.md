# 前端安全与数据保护

本文件规定前端代码如何处理不可信输入、会话、文件、配置和依赖。它不替代后端鉴权、业务权限、数据分级或组织安全制度；前端校验只能改善体验，不能成为最终安全边界。

## 不可信数据与安全渲染

- 后端响应、URL、路由参数、用户输入、上传文件名和第三方内容默认视为不可信，进入页面前经过类型校验、长度限制和必要的映射。
- 优先使用 Vue 模板文本插值和属性绑定；`v-html`、`innerHTML`、动态脚本、动态 URL 和任意 DOM 注入必须有明确来源、清洗方案和审查记录。
- 不把用户输入直接拼接到 HTML、CSS 选择器、脚本、正则表达式、请求地址或文件路径中。
- 外部链接和资源地址明确处理协议、来源和打开方式；禁止让不受信任的内容控制 `javascript:` 等危险协议。
- 第三方 Markdown、富文本、SVG、图表配置和导入数据先经过允许列表或可信渲染器，不依赖“当前数据看起来正常”。

## 会话与鉴权

- token、Cookie、刷新令牌和会话清理遵循项目统一基础设施；页面不自行复制登录失效、清 token、跳转和 reload。
- 不把长期凭据、密码或完整会话对象写入 `localStorage`、URL、日志或错误上报；确需持久化的状态使用版本化、最小化和可清理的存储。
- 前端路由守卫只负责导航体验和减少无效请求，后端仍必须校验身份、权限和资源归属。
- 401、会话过期、刷新失败和权限不足分别建模，避免所有失败都被处理成同一种“重新登录”。
- 涉及 Cookie、跨域、CSRF、CORS 或 iframe 时，先遵循后端和部署安全约定，不在前端私自绕过浏览器安全策略。

## 文件与浏览器能力

- 文件上传明确限制大小、类型、数量和文件名；前端检查只用于提前反馈，服务端仍需再次验证和安全处理。
- 文件预览、下载和对象 URL 使用完及时释放；不把本地文件内容、临时 URL 或完整响应无限期放入全局状态。
- 摄像头、剪贴板、通知、地理位置等浏览器能力按最小权限请求，说明失败、拒绝和不可用环境的恢复路径。
- 下载文件名、导出内容和预览 HTML 不能直接信任接口字段，避免路径、协议和内容注入。

## 配置、依赖与产物

- 前端构建产物中的变量默认对用户可见；禁止把服务端密钥、签名密钥或内部凭据编译进浏览器。
- 新增依赖检查来源、维护状态、许可证、漏洞和包体积；优先使用已有依赖，不因便利引入无法维护的运行时代码。
- 生产构建检查意外的调试入口、测试账号、Mock 处理器、内部地址、敏感 source map 和未使用的开发依赖。
- CSP、SRI、跨域策略和第三方脚本由部署与安全规范统一管理；前端变更要说明需要的配合，不通过内联脚本绕过限制。

## 日志与错误数据

- 日志、埋点、错误上报和网络诊断不得包含 token、密码、密钥、Cookie、完整身份信息或未脱敏业务对象。
- 错误对象保留可定位的 code、版本、请求 ID 和必要上下文；用户输入和后端原始响应按白名单字段采集。
- 处理异常时保留 `cause` 或内部诊断信息，但不要把堆栈、SQL、内部地址和安全策略细节直接展示给用户。

## 安全检查

涉及安全边界时至少确认：

1. 不可信数据的来源、校验、映射和渲染出口明确。
2. 会话、权限、401 和跨域处理复用了统一基础设施。
3. 文件、URL、HTML、SVG 和第三方内容没有未经处理地进入危险 API。
4. 生产产物不包含密钥、测试 Mock、调试入口和不必要的敏感 source map。
5. 依赖、日志、错误上报和浏览器权限没有扩大数据暴露面。
