# Skill 维护流程

## 新增

1. 在 `skills/<skill-name>/` 创建有效的 `SKILL.md`。
2. 按需增加 `references/`、`scripts/` 或 `assets/`。
3. 在 `manifest.yaml` 登记版本、状态、责任和依赖。
4. 更新 README 的 Skill 清单。
5. 执行 `./scripts/validate-skills.sh`。
6. 创建 Pull Request，完成 Review 后合并。

## 修改

判断改动是否影响触发范围、权限边界、输出契约、引用路由、其他 Skill 依赖或安装方式；影响时在 Pull Request 中说明兼容策略。修改后验证 frontmatter、引用链接、既有使用场景、版本和变更记录。

## 版本状态

`manifest.yaml` 默认使用语义化版本：`MAJOR` 表示不兼容变更，`MINOR` 表示兼容新增，`PATCH` 表示修复或澄清。状态使用 `draft`、`active`、`deprecated`、`archived`；废弃 Skill 必须说明替代项和移除计划。
