# 团队 Skill 使用指南

## 获取仓库

```bash
git clone <团队 Skill 仓库地址>
cd team-agent-skills
```

## 默认安装目录

| Agent | macOS | Windows |
| --- | --- | --- |
| Codex | `~/.codex/skills` | `%USERPROFILE%\.codex\skills` |
| Claude | `~/.claude/skills` | `%USERPROFILE%\.claude\skills` |
| Grok | `~/.grok/skills` | `%USERPROFILE%\.grok\skills` |

可通过 `CODEX_SKILLS_DIR`、`CLAUDE_SKILLS_DIR` 或 `GROK_SKILLS_DIR` 覆盖目标目录。

## 安装

macOS 按 Agent 批量安装全部内部 Skill：

```bash
./scripts/install-codex-macos.sh
./scripts/install-codex-macos.sh --force
```

Windows 使用对应的 `.ps1` 脚本，并使用 `-Force` 参数。安装器只创建链接，不复制内容；默认遇到同名目录会跳过，强制替换前会备份原目录。

## 更新

```bash
git pull --rebase
```

已有链接会自动使用更新后的仓库内容。新增 Skill 后，执行一次该 Agent 的安装脚本即可。

本地专属差异不要直接修改链接指向的团队 Skill，应在项目仓库或个人覆盖目录维护，成熟规则再回馈团队仓库。
